# アイテム工房

Minecraft統合版のカスタムアイテムを好きなだけ作り、Behavior Pack と Resource Pack をまとめた `.mcaddon` として保存するブラウザアプリです。

## 起動

`index.html` をブラウザで開きます。ビルドツールや追加ソフトは不要です。入力した設定や画像は外部へ送信されず、パックはブラウザ内で作られます。

## 見た目

Windows 95風の見た目には [win95.css](https://github.com/AlexBSoft/win95.css) 1.2.0 を使用しています。CSSと必要な画像素材は `vendor/win95/` に同梱しています。著作権表示とMITライセンスは `vendor/win95/LICENSE.txt` にあります。

## 使い方

1. パック名を決め、「アイテムを追加」で作りたい数だけアイテムを用意します。
2. 一覧からアイテムを選び、名前、ID、タイプなどを入力します。設定はアイテムごとに保存されます。
3. アイテムごとに画像を読み込み、あとから選び直すか、アイコンの色を選びます。画像はアップロード欄へのドラッグ＆ドロップにも対応しています。
4. 使いたいアクションをオンにしてコマンドを書きます。
5. 「アイテムパックを作る」を押し、保存した `.mcaddon` を開いてMinecraftへインポートします。
6. ワールド設定の「ビヘイビアーパック」で追加したパックを有効にします。リソースパックは依存関係から一緒に追加されます。
7. ワールド内で、各アイテムのプレビューに出ている `/give @s 名前空間:アイテムID` を使います。

## コマンドの実行

アクションに設定したコマンドは、アイテムを使ったプレイヤーの実行者・位置・向きで実行します。`@s` はそのプレイヤー、`~ ~ ~` はそのプレイヤーの位置です。コマンドは1行ずつ実行されます。先頭の `/` は付けても外しても使えます。

コマンドによってはワールドでチートを有効にする必要があります。作成したアイテムの操作スクリプトには `@minecraft/server` 2.5.0 を使うため、生成パックはMinecraft統合版 26.0 以降を対象にしています。

左クリックはアイテムを持った状態での腕振り、スニークとジャンプはボタンを押した瞬間を検出します。スニーク／ジャンプの操作時は、そのアイテムをメインハンドに持ってください。
